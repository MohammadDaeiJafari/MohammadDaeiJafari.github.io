# Mohammad Reza Daei Jafari — Personal Website

A responsive personal-brand website for GitHub Pages.

## Files
- `index.html` — website content
- `style.css` — design and responsive layout
- `script.js` — mobile menu and scroll animations
- `assets/images/` — optimized web images

## Updating photos
Replace the images in `assets/images/` while keeping the same filenames, or update the filenames in `index.html`.

## GitHub Pages
Repository name: `MohammadDaeiJafari.github.io`
Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
