# Mohammad Daei Jafari — GitHub Pages Website

## Publish it

1. Create a GitHub account at https://github.com/ if you do not already have one.
2. Create a new **public** repository named exactly:
   `YOUR-GITHUB-USERNAME.github.io`
3. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
4. In the repository go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose **main** and **/(root)**, then click **Save**.
7. After publishing, visit:
   `https://YOUR-GITHUB-USERNAME.github.io/`

GitHub says publication can take up to about 10 minutes after changes are pushed.

## Before publishing

Edit `index.html` and replace:
- `YOUR-EMAIL@example.com`
- Google Scholar `#`
- ORCID `#`
- LinkedIn `#`

Replace the placeholder CV file in `assets/` with your real PDF and keep the filename:
`Mohammad-Daei-Jafari-CV.pdf`

## Custom domain later

GitHub Pages supports custom domains. In **Settings → Pages**, enter your domain under **Custom domain**, then configure the DNS records at your domain registrar. GitHub's official documentation explains the exact records.

## Important

Do not upload private information, passwords, SSN, immigration documents, bank statements, or other sensitive files to a public repository.
