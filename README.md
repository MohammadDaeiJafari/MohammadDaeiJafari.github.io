# Mohammad Reza Daei Jafari — Personal Website

A dynamic, editorial-style personal brand website designed for GitHub Pages.

## Navigation
- Home
- About Me
- Daily Insights
- Research
- Books
- Media
- Conferences
- My Interests
- CV

## Before publishing
1. Replace the placeholder email in `index.html`.
2. Add your CV as `assets/Mohammad-Reza-Daei-Jafari-CV.pdf`.
3. Replace the two book placeholders with exact titles, covers, descriptions, and links.
4. Add your YouTube and podcast links in the Media section.
5. Add real Daily Insights posts over time.

## GitHub Pages
Repository name must be exactly:
`MohammadDaeiJafari.github.io`

Then go to:
Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.

The site will be available at:
`https://MohammadDaeiJafari.github.io/`

## Custom domain
If you later buy a domain such as `mohammad...com`, add it in:
Settings → Pages → Custom domain.
Then configure DNS at your domain provider.
